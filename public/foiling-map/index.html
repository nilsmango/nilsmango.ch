Foiling Map of the World

Posted on July 28, 2025 | #foiling #project7iii

I made something! It's a small website called foildata. It's a website where I will collect all the tools I build for foiling.

The first tool I made was an interactive table of parawings, where anyone can add parawings and compare them. As the number of entries exploded, I stopped updating it manually; but if you'd like to add a parawing or write a review, you're very welcome to contribute!

The second tool is the Foiling Map. You can quickly add your foiling spots (wave, wake thief, pump foiling, wing, whatever) along with schools, rentals, and downwind foiling runs. No login required. I made it so we can easily share the downwind runs we care about with new foiling friends or find new ones when visiting other places. Each spot lets you add any info you want, including Instagram or YouTube videos.
